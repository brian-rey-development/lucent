# Security

Lucent is pre-1.0. Security fixes land on `main` only.

## Reporting a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/brian-rey-development/lucent/security/advisories/new).
Include the affected version or commit, steps to reproduce, and the impact.

You will get an acknowledgement within 7 days. Please keep the report private until a fix is released.
